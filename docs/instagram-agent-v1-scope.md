# Instagram Agent V1

## Product context
- Paid Instagram agent inside Tichu
- Multi-user product
- Can be used by creators, SMM specialists, and agencies
- One user may work with one or multiple Instagram accounts depending on plan

## Target users
- Creator
- SMM specialist
- Agency

## V1 features
- Connect Instagram account
- Switch between connected accounts
- Profile audit
- Reel/Post link analysis
- Reel script generation
- Carousel text generation
- 30-day content plan
- Recent content performance summary

## Out of scope
- Autoposting
- DM automation
- Course assistant
- S3 video assistant
- Notifications
- Full competitor monitoring
- Publishing scheduler

## Required data
- Connected Instagram account
- Account profile info
- Posts/Reels metadata
- Captions
- Metrics / insights
- Optional brand voice notes

- Basic
